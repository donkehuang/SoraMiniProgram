# 部署API服务器到远程服务器

## 服务器信息
- IP: 8.211.175.227
- 用户: root
- 目标目录: /root/luckytalk-api

## 部署步骤（Windows PowerShell）

### 步骤1: 连接到服务器

```powershell
ssh root@8.211.175.227
```

### 步骤2: 创建项目目录

```bash
mkdir -p /root/luckytalk-api
cd /root/luckytalk-api
```

### 步骤3: 上传文件（在本地PowerShell执行）

打开一个新的PowerShell窗口，执行：

```powershell
# 进入api_server目录
cd C:\Users\donke\Desktop\LuckyTalk\api_server

# 上传必要文件
scp sora_api.py root@8.211.175.227:/root/luckytalk-api/
scp requirements.txt root@8.211.175.227:/root/luckytalk-api/
scp deploy.sh root@8.211.175.227:/root/luckytalk-api/
scp deploy_systemd.sh root@8.211.175.227:/root/luckytalk-api/
scp sora-api.service root@8.211.175.227:/root/luckytalk-api/
scp setup_https.sh root@8.211.175.227:/root/luckytalk-api/
scp nginx.conf root@8.211.175.227:/root/luckytalk-api/
scp .env.example root@8.211.175.227:/root/luckytalk-api/
```

### 步骤4: 配置环境变量（在服务器上执行）

```bash
cd /root/luckytalk-api

# 创建.env文件
cp .env.example .env

# 编辑.env文件，填入你的OpenAI API Key
nano .env
```

修改以下内容：
```bash
OPENAI_API_KEY=你的OpenAI_API_Key
```

保存并退出：`Ctrl + X`, `Y`, `Enter`

### 步骤5: 安装依赖

```bash
cd /root/luckytalk-api
bash deploy.sh
```

### 步骤6: 测试运行

```bash
cd /root/luckytalk-api
source venv/bin/activate
python sora_api.py
```

如果看到以下输出说明启动成功：
```
🚀 正在启动 Sora API 服务器...
📍 服务端口: 5000
📁 视频存储目录: /root/luckytalk-api/generated_videos
🔧 调试模式: False
```

按 `Ctrl + C` 停止服务

### 步骤7: 后台运行

```bash
cd /root/luckytalk-api
source venv/bin/activate
nohup python sora_api.py > server.log 2>&1 &
```

### 步骤8: 测试API

```bash
# 测试健康检查
curl http://localhost:5000/api/health

# 从外部测试（在本地PowerShell）
curl http://8.211.175.227:5000/api/health
```

### 步骤9: 配置开机自启动（可选）

sudo bash deploy_systemd.sh
```

### 步骤10: 查看日志

```

## 配置HTTPS（可选但推荐）

### 步骤10: 配置HTTPS（推荐）

⚠️ **重要：运行此脚本前，请确保域名已正确解析到服务器IP！**

#### 域名解析配置

1. 在域名服务商（如阿里云、腾讯云）添加A记录：
   - 主机记录：`www`
   - 记录值：`8.211.175.227`
   - TTL：`600`

2. 等待5-10分钟后，验证解析：
   ```bash
   ping www.enfuri51.xyz
   # 或
   dig +short www.enfuri51.xyz
   ```

#### 自动配置HTTPS

```bash
# 在服务器上执行
cd /root/luckytalk-api
sudo bash setup_https.sh
```

脚本会自动完成以下操作：
- ✅ 安装Nginx
- ✅ 安装Certbot（Let's Encrypt客户端）
- ✅ 自动申请SSL证书（免费）
- ✅ 配置Nginx HTTPS
- ✅ 配置HTTP自动跳转HTTPS
- ✅ 设置证书自动续期
- ✅ 配置防火墙

默认配置：
- 域名：`www.enfuri51.xyz`
- 邮箱：`m13236533199@163.com`

如果需要修改，运行时会提示输入。

#### 测试HTTPS

## 防火墙配置

如果API无法从外部访问，需要开放端口：

```bash
# 开放5000端口（如果使用HTTP）
sudo ufw allow 5000/tcp

# 开放80和443端口（如果使用HTTPS）
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 查看防火墙状态
sudo ufw status
```

## 故障排查

### 1. 服务无法启动
```bash
# 查看详细错误
cd /root/luckytalk-api
cat server.log

# 手动启动查看错误
source venv/bin/activate
python sora_api.py
```

### 2. 端口被占用
```bash
# 查看端口占用
netstat -tlnp | grep 5000

# 杀死占用进程
kill -9 <PID>
```

### 3. API无法访问
```bash
# 检查防火墙
sudo ufw status

# 检查服务是否运行
ps aux | grep sora_api.py

# 测试本地访问
curl http://localhost:5000/api/health

# 检查云服务器安全组
# 确保在阿里云控制台开放了5000端口
```
