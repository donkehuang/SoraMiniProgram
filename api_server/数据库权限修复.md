# 云数据库权限错误修复指南

## 错误信息
```
errCode: -502003 database permission denied
```

## 原因
云数据库`videos`集合的权限设置不允许小程序端直接写入数据。

## 解决方案

### 方案1：修改数据库权限（快速，适合开发测试）

1. **打开微信开发者工具**
2. **点击顶部菜单：云开发**
3. **进入云开发控制台**
4. **选择"数据库"**
5. **找到`videos`集合**
6. **点击集合名称右侧的"权限设置"**
7. **修改权限为以下之一**：

#### 权限选项：

**选项A：所有用户可读，仅创建者可写（推荐开发）**
```json
{
  "read": true,
  "write": "doc._openid == auth.openid"
}
```
- 适合：开发测试
- 说明：所有人可以查看视频，但只能修改自己的

**选项B：所有用户可读可写（仅用于测试）**
```json
{
  "read": true,
  "write": true
}
```
- ⚠️ 警告：任何人都可以修改/删除数据
- 仅用于开发测试，不要用于生产环境

**选项C：仅创建者可读写（最安全）**
```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```
- 适合：生产环境
- 说明：用户只能看到和修改自己的视频

### 方案2：使用云函数写入（推荐生产）

如果需要更严格的权限控制，创建云函数处理数据写入：

#### 步骤1：创建云函数

```bash
# 在cloudfunctions目录下创建
cloudfunctions/
  └── saveVideo/
      ├── index.js
      └── package.json
```

**index.js**:
```javascript
const cloud = require('wx-server-sdk')
cloud.init({
  env: cloud.DYNAMIC_CURRENT_ENV
})

const db = cloud.database()

exports.main = async (event, context) => {
  const wxContext = cloud.getWXContext()
  
  try {
    // 数据验证
    const { videoId, prompt, duration, size, orientation, fileID, httpURL } = event
    
    if (!videoId || !fileID) {
      return {
        success: false,
        error: '缺少必要参数'
      }
    }
    
    // 保存到数据库
    const result = await db.collection('videos').add({
      data: {
        videoId,
        prompt,
        duration,
        size,
        orientation,
        fileID,
        httpURL,
        status: 'completed',
        createTime: db.serverDate(),
        _openid: wxContext.OPENID, // 自动添加用户ID
        viewCount: 0,
        likeCount: 0
      }
    })
    
    return {
      success: true,
      _id: result._id
    }
    
  } catch (error) {
    return {
      success: false,
      error: error.message
    }
  }
}
```

#### 步骤2：修改小程序代码

```javascript
// 在 index.js 的 saveVideoToDatabase 函数中
async saveVideoToDatabase(videoId, uploadResult, timestamp) {
  try {
    console.log('[数据库] 调用云函数保存视频信息...')
    
    const res = await wx.cloud.callFunction({
      name: 'saveVideo',
      data: {
        videoId: videoId,
        prompt: this.data.prompt,
        duration: this.data.durationOptions[this.data.durationIndex],
        size: this.data.orientationIndex === 0 ? '1280x720' : '720x1280',
        orientation: this.data.orientationIndex === 0 ? 'horizontal' : 'vertical',
        fileID: uploadResult.fileID,
        httpURL: uploadResult.tempFileURL
      }
    })
    
    if (res.result.success) {
      console.log('[数据库] 保存成功:', res.result._id)
    } else {
      throw new Error(res.result.error)
    }
    
  } catch (error) {
    console.error('[数据库] 保存失败:', error)
    wx.showToast({
      title: '作品保存失败',
      icon: 'none'
    })
  }
}
```

## 常见错误

### 错误1：找不到videos集合
**解决**：手动创建集合
```
云开发 → 数据库 → 添加集合 → 输入"videos"
```

### 错误2：权限设置后仍然报错
**解决**：
1. 确保小程序已授权云开发
2. 重新编译小程序
3. 清除缓存后重试

### 错误3：_openid为空
**解决**：用户需要先登录
```javascript
// 在app.js中添加

  env: 'cloud1-2gd0041e12763b47',
  traceUser: true  // 自动获取用户openid
})
```
