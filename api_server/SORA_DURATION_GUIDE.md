# Sora视频生成 - 时长配置说明

## 🎯 支持的视频时长

### 当前配置：

小程序支持以下时长选项：
- ✅ **4秒** - 最短，适合短视频
- ✅ **8秒** - 中等，适合社交媒体
- ✅ **12秒** - 较长，适合展示

---

## 📊 时长对比

| 时长 | 适用场景 | 生成速度 | 适合平台 |
|------|---------|---------|---------|
| **4秒** | 短视频、快速预览 | 快 | 抖音、快手 |

## 🔧 API服务器配置

### Sora API参数：

```python
video = client.videos.create(
    prompt=prompt,
    model="sora-2",
    seconds=duration,  # 4、8、12
    size="720x1280"
)
```

### 当前限制：

**官方Sora API限制：**
- ✅ 支持4秒 - 8秒 - 12秒
- ⚠️ 不支持16秒（之前的配置错误）

**为什么改为4/8/12秒：**
- Sora API官方支持的时长
- 生成速度更快
- 成本更低

## 🔄 API服务器修改

### 当前代码（支持任意时长）：

```python
@app.route('/api/generate-video', methods=['POST'])
def generate_video():
    """生成视频的API接口"""
    data = request.json
    seconds = data.get('seconds', '8')  # 默认8秒

    video = client.videos.create(
        prompt=prompt,
        model="sora-2",
        seconds=seconds,  # 直接使用前端传来的值
        size="720x1280"
    )
```

### 小程序传参：

```javascript
const duration = durationOptions[durationIndex].replace('秒', '')
// 结果：'4', '8', '12'

wx.request({
  url: `${apiBaseUrl}/api/generate-video`,
  method: 'POST',
  data: {
    prompt: prompt,
    seconds: duration  // '4' 或 '8' 或 '12'
  }
})
```
