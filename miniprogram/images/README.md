# 图标说明

本目录需要添加以下图标文件（建议尺寸：81px × 81px）：

## 底部导航图标

### 首页 (Home)
- `home.png` - 未选中状态
- `home-active.png` - 选中状态

### 作品 (Works)
- `works.png` - 未选中状态
- `works-active.png` - 选中状态

### 我的 (Profile)
- `profile.png` - 未选中状态
- `profile-active.png` - 选中状态

## 其他图标

### 空状态图标
- `empty.png` - 作品列表为空时显示

### 用户占位图
- `user-placeholder.png` - 未登录时显示的用户头像

### Logo
- `logo.png` - 应用Logo（关于我们页面使用）

## 图标要求

- 尺寸：81px × 81px
- 格式：PNG
- 背景：透明
- 颜色：
  - 未选中：#666666
  - 选中：#667eea

## 临时解决方案

在添加真实图标之前，可以暂时使用纯色方块占位：
- 使用在线工具生成简单的图标
- 或者暂时注释掉tabBar的icon配置
